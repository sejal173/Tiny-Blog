# Tiny blog

Tiny Blog is a simple web application where users can create, view, update, and delete blog posts. The project demonstrates basic CRUD operations using a REST API and MongoDB

## Features
Create a new blog post
View all blog posts
View a single blog post
Update an existing blog post
Delete a blog post
Store and manage data using MongoDB

## Technologies Used
Node.js
Express.js
MongoDB
Mongoose
JavaScript

### Purpose
This project was created to practice backend development, REST API creation, CRUD operations, Express.js routing, and MongoDB database integration.
